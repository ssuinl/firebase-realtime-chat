# Firebase 실시간 1:1 채팅

2026.08 · 개인 개발 프로젝트

## 목적
Firebase를 이용해 사용자 인증과 실시간 메시지 교환을 지원하는 웹 채팅 서비스를 구현하는 프로젝트입니다.

## 주요 기능 (당시 작업 기록 기준)
- 사용자 인증
- 실시간 1:1 메시지 교환
- 이미지 전송
- 읽음 처리 및 답장
- 모바일 화면 대응

## 기술 스택
Firebase Authentication, Cloud Firestore, Firebase Storage, JavaScript, Firebase Hosting
